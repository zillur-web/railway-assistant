# Railway Ticket Assistant — Chrome extension

## ইনস্টল
1. Chrome-এর address bar-এ `chrome://extensions` খুলুন।
2. **Developer mode** চালু করুন।
3. **Load unpacked** ক্লিক করে এই `extension` ফোল্ডার নির্বাচন করুন।
4. Extensions মেনু থেকে **Railway Ticket Assistant** pin করুন।

## ব্যবহার
1. https://eticket.railway.gov.bd/ খুলুন। শর্তাবলির dialog থাকলে পড়ে নিজে সম্মতি দিন।
2. Home পেজে extension খুলে From, To, Date ও Class দিন। স্টেশনের নাম সাইটের ইংরেজি বানানে লিখুন।
3. ট্রেনের পুরো নাম বা নম্বর দিন। ১–৪টি সিট বেছে নিন (সাইটের নিজস্ব সীমা প্রযোজ্য)।
4. **Random** মোডে একই কোচের খালি সিট নেওয়া হয়; পাশাপাশি সিটের নিশ্চয়তা নেই। কোচ খালি রাখলে যথেষ্ট সিট আছে এমন কোচ খোঁজে।
5. **নির্দিষ্ট সিট** মোডে কোচের নাম এবং সিটের পুরো নম্বর দিন, যেমন `KA-1, KA-2`। সাইটে যে নাম দেখায় তা হুবহু লিখুন। সব সিট না পেলে অন্য সিট নেয় না।
6. **সিট বেছে OTP পর্যন্ত এগোন** চাপুন। সহকারী Search → নির্দিষ্ট ট্রেন/ক্লাস → কোচ → সিট → Continue ধাপ চালায়। এতে সাইটে সিট সাময়িক সংরক্ষণ এবং OTP পাঠানোর অনুরোধ হতে পারে।
7. OTP পেজে সহকারী থামে। সাইটে OTP নিজে দিন, যাত্রী তথ্য ও পেমেন্ট নিজে সম্পন্ন করুন। সাইট OTP না চাইলে যাত্রী তথ্যের পেজে থামে।
8. শুধু সার্চ ফর্ম পূরণ করতে **শুধু যাত্রার ফর্ম পূরণ** চাপুন।

পপআপ বন্ধ হলেও সাইটের নিচের প্যানেলে অগ্রগতি দেখা যায়। **থামান** বাটন পরবর্তী কাজ থামায়; ইতিমধ্যে নির্বাচিত সিট স্বয়ংক্রিয়ভাবে বাতিল করে না। Refresh/full navigation করলে কাজ থামে। লগইন/CAPTCHA বা শর্তাবলি নিজে সম্পন্ন করে আবার চালান। আগে থেকেই সিট নির্বাচন থাকলে সহকারী তা বদলায় না—নিজে Continue করুন বা সিট বাতিল করে আবার চালান।

## আপডেট (1.1.1)
স্টেশন autocomplete এখন সাইটের নিজস্ব widget দিয়ে চালু হয়। তালিকা দেরিতে লোড হলে সীমিত পুনঃচেষ্টা করে, এবং পুরোনো jQuery UI-এর anchor আইটেম সঠিকভাবে নির্বাচন করে। তালিকা না খুললে সেটিকে ভুল বানান বলে দেখায় না। পপআপে `v1.1.1` দেখে আপডেট নিশ্চিত করতে পারবেন।

স্টেশন ফিল্ডের mouse-enter activation ঠিক করা হয়েছে এবং সিট নির্বাচন থেকে OTP handoff যোগ হয়েছে। আপডেটের পর `chrome://extensions` পেজে Railway Ticket Assistant-এর Reload বাটন চাপুন, রেলওয়ের ট্যাব refresh করুন, তারপর আবার চেষ্টা করুন। ZIP থেকে ইনস্টল করলে আগে পুরোনো extension ফাইলগুলো নতুন ZIP-এর ফাইল দিয়ে প্রতিস্থাপন করুন।

Node.js, Laragon বা আলাদা server দরকার নেই। Extension যাত্রা, সিট পছন্দ ও কাজের সর্বশেষ অবস্থা শুধু Chrome local storage-এ রাখে; password, OTP বা payment ফিল্ডের মান পড়ে না। Extension সরালে সংরক্ষিত তথ্যও মুছে যায়।

এটি অনানুষ্ঠানিক সহকারী, স্বয়ংক্রিয় টিকিট ক্রেতা নয়। টিকিটের নিশ্চয়তা দেয় না। এটি refresh loop বা CAPTCHA bypass করে না। সাইটের HTML বদলালে selector update লাগতে পারে। তারিখের প্রাপ্যতা সাইটের ক্যালেন্ডার নির্ধারণ করে।

Permissions: `activeTab` (চাপার সময় বর্তমান ট্যাবে কাজ), `scripting` (ফর্ম ও বুকিংয়ের UI চালানো), `storage` (পছন্দ ও অবস্থা)। কোনো server/API key নেই। সরাসরি booking API কল করে না।

## যাচাই ও সীমাবদ্ধতা
`npm test` দিয়ে browser fixture-এ স্টেশন activation, রুট/ট্রেন যাচাই, random ও exact সিট, cancellation এবং OTP-তে থামা পরীক্ষা করা হয়েছে। সাইটের public UI scripts থেকে selectors যাচাই করা হয়েছে। লাইভ লগইন করা অ্যাকাউন্টে বাস্তব সিট সংরক্ষণ/OTP পাঠানো পরীক্ষা করা হয়নি। সাইটের পরিবর্তন, CAPTCHA, সিটের প্রাপ্যতা এবং reservation response-এর কারণে সহকারী থামতে পারে; তখন সাইটের বার্তা অনুসরণ করুন।

Chrome API reference: https://developer.chrome.com/docs/extensions/develop/concepts/activeTab
